Rules:
- category: exactly one of the category names above
- what: short natural description (e.g. "brown stain on front pocket")
- where: short region (e.g. "left sleeve")
- report physical issues first, marks second
- ALWAYS report visible logos / printed text ON THE ITEM as "print",
  even if you also find physical damage (print is preservation-critical)
- do not invent invisible damage
- report ONLY what is physically on the item. The background will be
  replaced, so NEVER report: watermarks or captions laid over the photo
  (e.g. a seller's shop name), UI overlays, background objects, shadows
