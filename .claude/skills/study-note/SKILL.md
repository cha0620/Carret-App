# study-note

`study/` 는 무엇을 만들었는지보다 **왜 그렇게 판단했고 무엇을 뒤집었는지**를 남기는 곳이다.

## 파일 규칙

- **하루 한 파일**: `study/YYYY-MM-DD-<주제-키워드>.md`. 같은 날 노트가 여러 개면 하나로 합친다.
- 맨 위: `# YYYY-MM-DD` + 섹션 목차(번호 목록). 본문 섹션은 `## N. 제목`, 본문에서 참조는 `§N`, `§N-M`.
- 이미 있는 섹션은 고쳐 쓰지 않고, 이어서 한 일은 **새 섹션**으로 붙인다 (오전/오후/저녁처럼).
  옛 섹션의 할 일 목록에서 끝난 것은 `[x] … → §N` 으로 체크만 한다.

## 섹션에 들어갈 것

- 문제 → 판단 → 한 것 (코드 위치, 커밋 해시)
- 선택지가 갈렸으면 **무엇을 골랐고 왜**, 처음 답이 틀렸으면 틀렸다고 적는다
- tester / reviewer 가 잡은 것 (표)
- 숫자: 테스트 통과 수, 측정값 — 직접 확인한 것만

## 마무리 ("오늘 마무리", "study 마무리")

마지막 섹션으로 `## N. 하루 마무리` 를 붙인다:

1. **PR 상태 표** — `gh pr list --state all --limit 10` 으로 확인 (머지/open, base)
2. **남은 일 한 목록** — 그날 모든 섹션의 `- [ ]` 를 모아 중복 제거, 끝난 것 빼고,
   "측정 / 정확도 / 구조·정리" 로 묶는다. 옛 목록 제목에는 "(최종 목록은 §N)" 표시
3. **교훈 세 줄**
4. 목차에 이 섹션 추가
