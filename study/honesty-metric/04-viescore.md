# VIEScore — Towards Explainable Metrics for Conditional Image Synthesis Evaluation (ACL 2024)

- 링크: <https://preview.aclanthology.org/setup/2024.acl-long.663>
- 읽은 정도: 검색 요약

## 요점

- VLM 에게 점수와 이유를 묻는 평가
- 생성(text-to-image)에선 사람과 비슷한 상관, **편집에선 약하다** — 저자 스스로 밝힘

## 배운 것

- "VLM 하나에 0~10 점수" 로 편집 결과의 보존을 재는 건 부족하다
- 우리 judge 성적표(eval 전용)도 같은 한계 — 보증 근거로 쓰지 않는다
