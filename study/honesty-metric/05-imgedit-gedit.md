# ImgEdit-Judge · GEditBench v2 · GIE-Bench — 편집 심사 모델과 보존 점수

- ImgEdit: <https://arxiv.org/pdf/2505.20275>
- GEditBench v2: <https://arxiv.org/html/2603.28547>
- 읽은 정도: 검색 요약

## ImgEdit-Judge (2025)

- Qwen2.5-VL-7B 를 편집 평가 약 20만 건으로 학습
- 사람 점수와 **±1점 안 약 70%** — GPT-4o-mini · 기본 Qwen 보다 낫다. 단 검증 60장뿐

## GEditBench v2 (2026-03)

- 사용자 질문 1,200 · 23 과제. "기존 지표는 **시각적 일관성**(바꾸지 말 곳이 그대로인가)을 못 잡는다"
- PVC-Judge: 일관성 전용 **두 장 비교** 심사(오픈), 전문가 선호쌍으로 검증 — GPT-5.1 보다 낫다고 보고

## GIE-Bench (2025)

- 지시한 편집이 됐는지는 자동 생성 객관식 질문으로, 보존은 **마스크 밖 보존 점수**로 따로

## 배운 것

- 학습한 심사 모델도 사람과 70% 수준 — 심사 모델 하나로는 보증이 안 된다
- **두 장 비교(원본 vs 결과)** 형식이 일관성 판단에 맞다 — 우리 원본 대조 검사도 두 장을 같이 보여 준다
- "바꿀 곳" 과 "바꾸지 말 곳" 을 따로 잰다 — 칠하기(§3)에선 칠한 곳 밖은 픽셀로 보장하니 안쪽만 재면 된다
